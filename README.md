# Wishlist — установка и пользование

Как это устроено:
- **Страница** живёт на GitHub Pages, например `laurashlyakova25.github.io/wishlist`. Её видят гости, и через неё же вы ведёте список.
- **Данные** хранятся в вашей закрытой Google Таблице. Таблицу никому не открываете и сами можете в неё не заходить.
- **Связь** между страницей и таблицей — маленький скрипт Google Apps Script (файл `Code.gs`).

| Файл | Зачем |
|---|---|
| `Code.gs` | Скрипт для Google Таблицы (вставляется в таблицу, на GitHub лежит просто для хранения) |
| `index.html`, `styles.css`, `app.js` | Страница |
| `config.js` | **Единственная настройка** — адрес скрипта |
| `manifest.webmanifest`, `sw.js`, `icon*.png`, `icon.svg`, `apple-touch-icon.png`, `favicon-32.png` | Иконка-подарок и установка на экран телефона |

Всё делается с компьютера, ≈20 минут, один раз.

---

## Шаг 1. Таблица и скрипт

1. Откройте [sheets.new](https://sheets.new), назовите таблицу «Wishlist».
2. **Расширения → Apps Script.**
3. В файле `Код.gs` удалите всё и вставьте содержимое `Code.gs`. Сохраните (Ctrl+S). **Других файлов создавать не нужно.**
4. ⚙️ **Настройки проекта** → часовой пояс **(GMT+03:00) Москва**.
5. Вверху выберите функцию **`setupWishlist`** → **▶ Выполнить** → **Проверить разрешения** → ваш аккаунт.
6. «Приложение не проверено» — это нормально для личного скрипта: **Дополнительные настройки → Перейти на страницу (небезопасно) → Разрешить**. Разрешения нужны, чтобы писать в таблицу, сохранять загруженные фото и резервные копии на вашем Диске.
7. **Развернуть → Новое развертывание** → ⚙️ **Веб-приложение**:
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все**
   - **Развернуть**
8. Скопируйте **URL веб-приложения** (заканчивается на `/exec`).

> **Уже ставили прошлую версию?** Замените текст `Code.gs`, удалите файлы `Index`, `Styles`, `App` и снова запустите `setupWishlist`. Затем **Развернуть → Управление развертываниями → ✏️ → Версия: Новая версия → Развернуть**.

## Шаг 2. GitHub

1. На [github.com](https://github.com) нажмите **New repository**. Имя: `wishlist`, **Public**, **Create repository**.
2. Нажмите **uploading an existing file**. Перетащите **все файлы из архива** (без папки — так же, как в календаре) → **Commit changes**.
3. Откройте `config.js` → ✏️ (Edit). Вместо `ВСТАВЬТЕ_СЮДА_АДРЕС_EXEC` вставьте адрес из шага 1.8, кавычки оставьте. → **Commit changes**.
4. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → **Save**.
5. Через 1–2 минуты страница откроется по адресу `https://laurashlyakova25.github.io/wishlist/`.

## Шаг 3. Вход владельца и иконка на телефоне

1. В таблице на листе **СПРАВОЧНИКИ** найдите настройку **«Адрес страницы (GitHub Pages)»** и вставьте адрес из шага 2.5.
2. Обновите таблицу и откройте **Wishlist → Ссылки: для гостей и для меня**.
3. Откройте **секретную ссылку владельца** (п. 3 в окне) **на своём телефоне**. Сверху появится «Режим владельца», снизу — панель. Телефон это запомнит.
4. Добавьте страницу на экран как приложение — появится иконка-подарок:
   - **iPhone:** Safari → «Поделиться» → **«На экран „Домой“»**.
   - **Android:** Chrome → ⋮ → **«Установить приложение»** или **«Добавить на главный экран»**.
5. Гостям отправляйте **обычную** ссылку, без `#owner=…`.

> ⚠️ Секретную ссылку никому не пересылайте. Если она случайно ушла: **Wishlist → Сменить секретную ссылку владельца**, затем откройте новую из «Ссылок».

## Как вести список из приложения

Внизу экрана — панель владельца:

| Кнопка | Что делает |
|---|---|
| **＋ Желание** | Новое желание: название, описание, категория, подкатегория (из списка или своя), приоритет, **фото с телефона** (кнопка «Загрузить фото») или ссылка на картинку, цена, ссылки на магазин, характеристики, пожелания, личный комментарий 🔒 (видите только вы) |
| ✏️ на карточке | Изменить всё то же, сменить **статус**, скрыть от гостей, **удалить**. Удалённое не пропадает: строка уходит на лист **КОРЗИНА** в таблице |
| **История** | Действия (кто что выбрал и отменил), деньги (вклады и итоги по валютам), повторы (сколько раз и кто дарил кофе, цветы…) |
| **Настройки** | Название и подзаголовок страницы, валюта, показывать ли гостям «Исполненные», кнопка «Скопировать ссылку для гостей», выход из режима владельца |
| 👁 | «Как видят гости» — посмотреть страницу глазами гостя |

**Статусы:**
- **В списке** — свободно.
- **Присмотрено** — для себя, гости всё равно могут выбрать.
- **Подарят** — гость нажал «Подарю это».
- **Получено** — подарок у вас, желание уходит в «Исполненные».
- **Больше не актуально** — уходит во вкладку «Скрытые», видную только вам.

**Кто дарит — сюрприз.** На карточке видно только «Кто-то уже выбрал этот подарок». Имя появится, если нажать «показать кто».

**Категории:**
- **Ежемесячные** группируются по месяцам (месяц выбирается в форме).
- **Редкие** — с полями «Когда примерно» и «Желаемый бюджет».

**Повторяющиеся желания** (кофе, цветы, ужины). В форме выберите **«Повторение»**:
- **Неограниченно** — можно дарить сколько угодно раз подряд.
- **Периодически** — снова доступно через интервал: ежедневно, еженедельно, ежемесячно, раз в 3 месяца, раз в полгода, ежегодно или свой интервал в днях.
- **Впечатление** — рестораны, кофейни, поездки (с интервалом или без).

Укажите «Обычно за раз», «Сумма от» и «до». Гость нажимает **«Подарить»** и выбирает только сумму в этом диапазоне — место и время решаете вы. Желание не копируется и не исчезает: счётчик растёт, а в истории видно, кто и когда дарил. Если нужно, чтобы цветы стали доступны раньше срока, нажмите в форме **«сделать доступным сейчас»**.

## Что могут гости

- **«Подарю это»:** имя + галочка, и у всех желание становится «Уже дарят». Никаких кодов. Передумал — кнопка «Отменить» на карточке, **с того же телефона**. С другого устройства отменить нельзя; тогда пусть напишет вам, а вы вернёте статус «В списке».
- **«Подарить»** — для повторяющихся желаний.
- **«Вклад»** и **«Подарить деньги»** — добровольная сумма на конкретное желание или без привязки. Желание при этом не занимается.
- Если двое нажмут «Подарю это» одновременно, получится только у одного: второй увидит «Это желание уже кто-то дарит».
- Сайт **не принимает и не переводит деньги** — он только записывает, кто, сколько и на что подарил.

## Обслуживание

- **Изменили `Code.gs`** → Apps Script → **Развернуть → Управление развертываниями → ✏️ → Новая версия → Развернуть**. Адрес `/exec` останется прежним.
- **Изменили файлы сайта** → загрузите их в репозиторий поверх старых. Страница обновится через 1–2 минуты (на телефоне иногда нужно закрыть и открыть приложение).
- **Резервные копии:**
  - **Wishlist → Включить ежедневное копирование** — копии хранятся в папке «Wishlist — резервные копии» на Диске, последние 30.
  - Плюс **Файл → История версий** в таблице.
- **Фото** из приложения сохраняются в папку «Wishlist — фото» на вашем Диске с доступом «по ссылке» (иначе гости их не увидят).
- **Таблицу можно править и вручную** — в приложении всё появится сразу. Новые столбцы добавлять можно, переименовывать стандартные нельзя.

## Если что-то не так

| Что видите | Что сделать |
|---|---|
| «Почти готово… откройте config.js» | В `config.js` не вставлен адрес `/exec` или он с ошибкой |
| «Нет связи» | Проверьте, что у развертывания доступ **«Все»**. Откройте адрес `/exec` в браузере: должен показаться текст, начинающийся с `{"ok":true` |
| «Таблица ещё не настроена» | Запустите `setupWishlist` / **Wishlist → Настроить / обновить таблицу** |
| Изменили скрипт, но ничего не поменялось | Нужна **новая версия** развертывания (см. «Обслуживание») |
| Режим владельца пропал | Откройте секретную ссылку снова (Wishlist → Ссылки) |
| Не загружается фото | Разрешите доступ к Диску: запустите `setupWishlist` ещё раз и подтвердите разрешения |

## Проверьте после установки (5 минут)

1. Гостевая ссылка открывается на телефоне без входа в Google.
2. С гостевой ссылки: «Подарю это» → «Отменить».
3. С двух телефонов: «Подарю это» на одно желание — проходит только один.
4. «Кофе в кофейне» → Подарить два раза подряд → «Исполнено 2 раза», карточка одна.
5. В режиме владельца: добавить желание с фото с телефона → оно появилось у гостя.
6. ✏️ → «Получено» → желание ушло в «Исполненные».
7. «История» показывает все действия выше.
8. Иконка-подарок на экране телефона.

- Логика сервера — 61 автотест через те же точки входа, что вызывает страница: «Подарю это», отмена, двойной выбор, вклады, повторы, доступ владельца, добавление, изменение, удаление, загрузка фото, настройки.
